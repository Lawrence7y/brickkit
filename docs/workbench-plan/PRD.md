# BrickKit 零件工作台 PRD

版本：1.0；日期：2026-10-27。本文是用户已确认方向的实现规格；下列布局、交互和文案为本次补全的产品决定。技术实现可以适配仓库，不能自行删减需求。本文不声明当前功能已经实现。

## 1. 目标与范围

把现有查看器扩展为「零件库 → 详情 → 待选区 → 模型装配 → 试玩 → 展示与图纸」的完整工作台。零件与模型始终是视觉主角，位置连续的动画表达物件从哪里来、到哪里去。

优先验证灯笼装配；飞机修复暂缓。编辑器与灯笼修复独立并行。第一阶段交付完整基础编辑链；第二阶段交付转动/折叠/滑动与联动。球形关节、齿轮/连杆闭环、重力摩擦为后续能力，页面明确显示不支持，不能用假动画冒充。

优先级：真实连接与状态正确 → 不丢数据、可撤销 → 完整操作链 → 物件连续动画 → 性能优化。不得用漂亮吸附掩盖错误扣合。

## 2. 统一视觉规格

- 默认明亮工作台：页面 #F5F6F8，面板 #FFFFFF，主文字 #20242B，次文字 #687180，边线 #E0E4EA。
- 主操作/选中 #3769E8，合法接口 #1B9367，存疑 #B77915，错误 #D34444；状态同时有图标和文字，不只靠颜色。
- 中文系统字体，正文 14px，辅助信息 12px，区块标题 16px，页面标题 20px；行高 1.5。卡片圆角 12px，弹窗 20px；控件最小高 36px，触摸目标不低于 44px。
- 灰模使用目录已有的中性灰颜色；灰模是预览材质，不修改目录颜色、BOM 或已放零件。选中轮廓 2px，悬停 1px。禁止大面积渐变、无意义装饰和巨型标题挤压模型。
- 桌面基准 1440×900；同时验证 1280×720、1920×1080、768×1024、390×844，无整页横向溢出。

## 3. 页面自上而下的确定结构

### 3.1 顶栏（48px）

左：BrickKit 标识、可编辑模型名（空模型为「未命名搭建」）。中间：分段按钮「搭建 / 试玩」。右：状态「已保存 / 正在保存 / 保存失败」、按钮「打开」「保存」「更多」。

打开支持 .brick.json 和工作台草稿；有未保存改动时显示「保存草稿后打开 / 放弃改动并打开 / 取消」。更多菜单固定为「新建搭建」「导出模型 JSON」「导出 LDraw」「使用说明」。新建同样先保护未保存改动。导出不覆盖正式示例。

### 3.2 待选条（112px）

紧接顶栏，左侧 128px 固定区：「零件库」主按钮、下方「待选 N 种」。右侧为单行横向滚动的待选卡，左右溢出箭头；滚动只影响条内。名称统一使用「待选区」，不混用候选区。

待选卡 88×88px，顶部 60px 物件缩略图，底部编号及「∞」或库存余量，角落圆色点；悬停显示名称。选中蓝边。卡片右上菜单：「设置颜色与数量」「复制为其他颜色」「移出待选区」。默认自由搭建，无限供应；右端按钮「库存：不限」可切到有限库存。

空态：小灰砖＋「先从零件库挑选零件」＋「打开零件库」。同类型同颜色合并，同类型不同色独立卡。改色撞到已有卡时合并数量；自由模式保持无限。删除待选卡不删除已装零件。

### 3.3 模型工作台

占据首屏剩余高度，最小 420px，背景与页面一致。画面中央是模型，地面细网格默认开启，有小型 XYZ 方位指示。首次加载现有模型时构图占可用画面约 70%，不裁切。

左侧悬浮竖工具条（44px 宽）：「选择 V」「移动 G」「旋转 R」「涂色 C」「接口 I」。上方居中显示当前工具提示；右上按钮「检查」，带错误/警告数量；右下为「放大」「缩小」「适合模型」「重置视角」。底部居中显示暂态放置操作。底部右侧常驻「撤销」「重做」。

默认无属性侧栏，保证模型可见。选中零件后右侧出现 300px 浮层，容器为它保留视觉安全区，模型不被遮挡。左上角小标签显示「搭建模式」或「试玩模式」。底部有「向下查看展示 ↓」按钮。

### 3.4 滚动过渡区

工作台之后提供 0.8×视口高的滚动行程。滚动开始前是搭建构图，结束后为现有展示构图。过渡期间固定呈现同一模型，连续插值容器位置/尺寸及投影尺度，不修改任何零件物理坐标。

进度 0～0.25：工具与待选条淡出并禁用命中；0.15～1：模型显示包围框连续等比缩至桌面可用宽的 68%，中心移动到展示左栏中心；0.6～1：展示控制侧栏淡入。模型保持朝向、关节姿态、颜色与选择；不自动旋转，不重载模型，不恢复默认姿态。尺寸变化不得因滚动抖动或反向而跳变。

向上滚动完全反向恢复。正在放置/移动预览时，滚动不提交改动：先取消预览、保留待选项并短提示「已取消临时放置」，随后过渡。弹窗打开时锁定页面滚动。编辑器不捕获普通滚轮，滚轮用于页面；Ctrl/⌘+滚轮、捏合和按钮用于场景缩放。

### 3.5 展示区及图纸

保留现有「3D 展示 / 拼装图纸」切换、拼装步骤播放、爆炸图、模块列表、机关、零件清单、数据与校验、下载 JSON/LDraw、打印 PDF。展示左侧模型、右侧 320px 控制栏；有「返回搭建 ↑」按钮。

爆炸图/步骤播放属于展示变换，不回写装配坐标和连接；返回搭建时清除爆炸/步骤隐藏，显示完整模型，保留用户关节姿态。无步骤的草稿使用一个「完整模型」步骤，不伪造拼装次序。编辑后旧图纸缓存失效，重新生成并显示进度。空模型不生成空白图纸，提示「先添加零件」。

下方页脚仅显示「BrickKit · 保存在本机」和「使用说明」。不增加营销区块。shot 渲染与直接 #view=book 必须绕过滚动工作台，保持原命令行渲染/图纸能力。

## 4. 零件库与详情的完整规格

### 4.1 零件库弹窗

桌面宽 min(1120px, 视口宽−64px)、高 min(760px, 视口高−64px)。标题「零件库」、右上关闭；顶部搜索「搜索名称、编号或尺寸」，清空按钮；左侧 160px 分类，右侧虚拟网格，卡片最小 120×136px，间距 12px。

分类固定顺序：「全部」「砖」「板」「光面板」「斜面与楔形」「圆形与弧面」「侧凸点与支架」「夹子与杆」「合页与关节」「科技与车轮」「门窗与其他」「收藏」。通过统一映射读取已有目录 category/kind，不把原目录改成 UI 分类；未知项进入其他。

筛选行：「装配能力：全部 / 可装配 / 仅展示 / 待核实」，默认全部；结果数量；排序「常用 / 编号」。常用依据本机添加次数，无记录按编号稳定排序。全部表示当前收录目录并集，不承诺覆盖世界全部乐高零件。

卡片：灰模缩略图、中文名（无中文显示原名）、编号、尺寸、能力小标。仅可展示件仍可进入详情与待选区，但在装配前说明限制。无结果：「没有找到零件」「清除筛选」。几何缺失显示轮廓占位及「几何未就绪」，不画错误替代件。

### 4.2 从网格打开详情

点击卡片，零件预览从卡片图像矩形移动/放大到详情预览矩形，320ms cubic-bezier(.22,1,.36,1)。原卡片保留占位。背景网格变暗，文字在最后 120ms 淡入。详情使用弹窗内新视图，顶部「← 返回零件库」、右上关闭。

详情左 60% 为 3D 预览，右 40% 为信息。初始灰模，保留卡片观察方向；拖动自由旋转、捏合缩放，按钮「复位视角」「自动旋转」（默认关）。信息依次：名称、编号、尺寸、分类、接口数量与类型、装配能力及原因、来源。未知写「尚未核实」，不猜测。

底部固定「数量」步进器（默认1、1～999）、按钮「添加到待选区」。默认灰色加入，在待选区配色；用户曾设同款颜色时仍默认灰，避免隐式继承。添加后预览保留，复制一个物件缩略体沿路径飞向待选卡，360ms，卡片数量更新；弹窗不自动关闭。若待选条被弹窗遮挡，动画终点用固定可见的「已选 N」托盘，关闭时再映射到待选条，不飞向不可见区域。

返回库时 260ms 回到原卡，保留搜索/分类/滚动；原卡不可见则退化为淡出，禁止飞到错误卡。关闭后焦点回到打开按钮。手机详情为全屏，预览上半部、信息下半部、底部固定添加按钮。

## 5. 待选区、取件和装配

### 5.1 待选项设置

点击卡片取件；卡片菜单/色点打开小面板，标题「设置零件」，包含颜色网格、颜色名称/编号、数量及供应模式。颜色只提供目录已支持的颜色码，不捏造。自由模式显示「不限次数」，有限模式显示剩余件数。有限库存归还按原类型/当前色合并，没有卡则创建；仅删除模型件时提示「归还待选区 / 直接删除 / 取消」。

### 5.2 放置状态机

状态固定为 idle → selected-in-tray → placing-preview → attached 或 loose；取消回 idle。click 和 drag 共用状态机；拖拽释放只进入预览，不直接提交；点击模型确认位置。预览不进入 BOM、不扣库存、不触发保存或历史。

模型为空：第一件默认吸附地面网格，确认后为明确 root。非空时优先接口扣合；接近有效接口显示最多8个候选（其余可切换），Tab/Shift+Tab切换；R切换引擎提供的合法朝向，禁止自行捏造扣合坐标。当前候选绿色、占用灰色、冲突红色，提示具体对象。

底部操作条：「确认放置 Enter」「切换接口 Tab」「旋转 R」「取消 Esc」「暂放工作台」。确认必须再次检查占用和碰撞；候选过期重新求解，不沿用旧状态。暂放显式为 loose，提示「未连接，不计为装配完成」；不伪装成主体根件。默认单次放置；复选「连续添加」开启后保留同款预览，Esc结束。有限库存为0时卡片禁用取件并显示「已用完」。

位置错误文案按实际原因：「接口不匹配」「接口已占用」「与 {零件编号/实例} 相撞」「该零件接口尚未支持」「没有合法候选」。不支持时仍允许暂放，不允许标绿。

动画：取件从待选卡抬起到指针160ms；候选位置平滑预览80ms，不插值实际数据；确认扣合120ms，禁止沿会穿过实体的路径表演；无法证明路径安全时使用原位高亮，不飞穿模型。Esc/右键取消；右键未在预览中用于相机，不弹删除菜单。

## 6. 已添加零件的编辑

默认左键点击选中；Shift点击增减多选，点击空白取消；框选仅在按住Shift拖动空白时发生。空白拖动旋转相机，中键或Space+拖动平移，触屏一指空白旋转、双指平移/捏合缩放。点中关节只在试玩中驱动。

属性面板固定顺序：缩略图/名称/编号/实例ID；「颜色」；「位置与朝向」；「连接」；「操作」。位置按明确单位 x/z格、y片；旋转仅展示该接口/引擎允许的方向，不能把精确变换默默舍入。连接逐条显示另一实例、双方接口、固定/关节类型、证据状态。

移动已连接件弹出轻量选择：「移动整个固定组件」「断开选定连接后移动」「取消」。前者沿固定连接求组件；若仍固定到主体则说明「该组件仍被固定」，不能拖散模型。预览中移动/旋转不提交；Enter确认，Esc复原。只有通过验证的扣合才能写 attached；连接状态只读计算，不提供勾选「已连接」。

更换零件：先预览能保持的连接；无法保持则显示受影响连接，选「断开后更换」或取消，不自动改父件。复制生成新实例进入放置预览，不复制虚假外部连接。删除/拆下先列出因此断开的后续组件，允许显式保留为未连接，拒绝静默遗留。撤销恢复零件、颜色、连接、库存与姿态，作为一笔事务。

涂色工具：左侧C按钮打开下方色板（常用色＋全部色），显示色名/编号。鼠标移过零件仅预览，点击才提交，可连续涂色；空白点击不改色；Esc退出。多选时提供「应用到所选N件」单独确认。颜色更改不影响位置/连接。H隐藏所选，面板提供「显示全部」；隐藏只影响可见性。

## 7. 可动结构与试玩

固定连接构成刚体组件；转动、折叠、滑动连接分隔组件。轮胎与轮毂是否一起动、轴是否跟随，来自实际连接类型，不能遍历所有连接无差别带动。

建关节面板：从已识别兼容接口建立，显示「固定端」「活动端」「将随动的N件」（高亮）、轴、范围、当前值、名称。轴优先由接口推导，不接受普通砖任意声明成关节。无法确认的范围标待确认，不称物理限位。原模型 mechanisms 可作为待验证声明导入。

试玩模式隐藏取件/涂色，保留选择、相机和关节列表。点击活动件显示旋转弧或滑动箭头，拖动只在允许自由度内；右侧同步数值/滑块。固定组件跟随，子关节保存自身角度；到范围限位停止。碰撞预测命中停在上一个可接受姿态并提示对象。采样/代理局限常驻说明「几何近似检查，未代替实物验证」，不保证采样间无碰撞。

运动不得改写装配基准坐标；关节姿态单独保存。按钮「恢复初始姿态」「保存当前姿态」「展开」「收起」；后两项仅在存在明确预设时启用。循环约束、多固定路径、球关节/齿轮等未支持时锁定该操作并指出原因，不用任意旋转代替。

第一阶段需交付固定组件跟随及模式框架；第二阶段必须用一个车轮样本、一个折叠件及至少两级关节样本证明联动，不能用灯笼无关节来代替验收。

## 8. 数据、安全和性能

- 场景渲染与装配模型分离；草稿含schemaVersion、模型快照、待选项、库存、接口连接、关节及姿态、证据状态、视角。接口ID和实例ID必须稳定，不能用数组顺序代替身份。
- 自动保存使用IndexedDB，事务提交后500ms防抖；显式保存下载工作台草稿。现有brick.json仍可打开/导出。失败显示「保存失败，请下载草稿」，保留内存状态；损坏文件不覆盖当前模型。
- 每次添加/修改连接使用候选→复核→提交；历史至少100笔。临时预览、相机和滚动不进入建模历史。
- 使用统一mergeCatalogParts。src/core/actions-v1含Node crypto等依赖，不得直接打进浏览器；优先写隔离适配层，功能不足先登记给核心所有者。浏览器不引入Node polyfill大包来掩盖架构问题。
- 全库网格虚拟化，静态缩略图按需生成/缓存，详情与主场景少量WebGL上下文复用；不为每张卡开canvas，不每帧扫描全库，不把整库几何强行内嵌单HTML。
- 单文件模型查看器保持离线可用；全库工作台允许本地资产包。两者分清交付入口和资产依赖，不能默认通过CDN联网加载来满足离线导出。
- 建议性能目标（需记设备/浏览器及模型规模）：200件模型相机/缩放平均≥50fps、放置反馈p95≤150ms；达不到报告实测瓶颈，不能虚报。UI普通过渡160～360ms；滚动过渡跟随进度，不靠队列补播。

## 9. 响应式、键盘和异常态

≥1200px按桌面规格；768～1199px零件库分类压为120px、属性面板280px；<768px待选条96px、属性为底部抽屉最高45vh、零件库全屏/分类横向chips、展示控制在模型下方，模型最终宽度为可用宽的92%。不把桌面浮层简单缩小塞进手机。

键盘Enter确认、Esc取消/关闭、Tab切候选（仅放置中）、V/G/R/C/I切工具、Delete删除（先保护连接）、Ctrl/⌘+Z撤销、Shift+Z重做。输入框编辑时不响应快捷键。弹窗焦点圈闭、关闭归还焦点；所有图标有中文aria-label。reduced-motion关闭飞行/缩放长动画，用淡入/即时位置变化保留信息。

几何/目录加载显示骨架和重试；无WebGL显示解释并允许下载数据；窗口调整时重算动画目标不重建模型；交互取消、保存失败、导入失败不丢模型。说明面板解释按键、未连接状态与验证边界，不塞开发路径/错误堆栈。

## 10. 与旧页面的逐项迁移

| 旧内容 | 新位置与行为 |
|---|---|
| appbar模型名、视图切换 | 名称进入顶部；展示/图纸切换进入下方展示区 |
| stage模型canvas | 作为共享场景，贯穿工作台与滚动过渡、展示；shot保持直达 |
| reset按钮 | 右下视角工具，展示仍可用 |
| stepbar | 展示模型下方，搭建模式不悬盖模型 |
| 爆炸图/模块/机关 | 展示右栏；编辑关节属性独立于展示机关滑块 |
| BOM | 展示右栏「零件清单」，模型编辑后实时重算 |
| 数据与校验 | 展示折叠区＋工作台「检查」入口共用结果 |
| 文件按钮 | 顶栏打开/保存/更多；展示仍提供导出入口 |
| book/pages | 保留打印路径，编辑后失效重算，不重做排版系统 |
| toast | 保留短反馈；验证细节进入检查面板，不用toast承载全部错误 |

## 11. 交付与验收

阶段A：库/详情/待选/灰模/颜色/装配预览/固定组件/历史与保存/滚动/原展示兼容。阶段B：轮子、折叠、滑动、多级跟随与运动检查。每阶段能运行和复现，不能只有静态mockup；最终必须交付A+B。

验收用例：

1. 全库搜索、分类、详情自由旋转、返回恢复位置；灰模不污染真实颜色。
2. 添加同件同色合并、不同色分开；连续放置、取消、库存耗尽/归还正确。
3. 合法扣合成立；错接口、占用、碰撞被拒；暂放不算连通。
4. 改色两条路径、位置修改、组件移动、复制/删除、撤销/重做后数据一致。
5. 库→详情→待选→装配动画有明确起终点；快速重复操作不产生幽灵件/双重提交。
6. 上下滚动连续等比变化，反向不跳，朝向/姿态/数据不丢；reduced-motion可用。
7. 轮子/折叠/滑动/两级关节真实样本，固定端不动，随动组正确；不支持项明确拒绝。
8. 灯笼修复产物直接加载编辑，但UI会话不写正式灯笼文件。
9. 原CLI render、viewer、booklet、export-ldraw、#view=book与shot链路保留。
10. 浏览器真实交互验证上述五种尺寸、刷新恢复、损坏导入、保存失败和无几何态；保留截图、录屏/帧序列和日志。单元测试不替代操作验收。

交付：源码、运行/构建方法、可打开入口、自动化结果、浏览器证据、已实现/未验证/不支持清单。报告不用测试总数代表交互或实物验收。范围变更必须写明原因，不自行删除功能。

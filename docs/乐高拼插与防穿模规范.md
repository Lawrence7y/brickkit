# 乐高拼插物理规律与防穿模规范

本文档规定了 BrickKit 将实物照片转化为 3D 乐高模型时必须遵守的**几何尺寸换算、凸点-底孔扣合规则、零穿模硬约束**以及 **12 大类 165 种标准零件目录**的使用方法。任何调用 BrickKit 的 Agent（Harness）或建模者在输出 `.brick.json` 时均受本规范与 `brickkit validate` 的强制约束。

---

## 一、乐高基础几何换算（5:2 定律）

乐高积木之所以能在水平与竖直六个方向（SNOT，Studs Not On Top）严丝合缝地拼插，源于其严格的 **LDU（LDraw 单位）比例**：

| 物理量 | 毫米 (mm) | LDraw 单位 (LDU) | BrickKit 格单位 (`stud`) | BrickKit 层单位 (`plate`) |
| :--- | :---: | :---: | :---: | :---: |
| **1 格（水平凸点间距 Stud Pitch）** | `8.0 mm` | `20 LDU` | **`1.0 格`** | **`2.5 片`** |
| **1 片（板厚 Plate Height）** | `3.2 mm` | `8 LDU` | **`0.4 格`** (`PLATE = 0.4`) | **`1.0 片`** |
| **支架壁厚（Bracket Lip Thickness）** | `1.6 mm` | `4 LDU` | **`0.2 格`** | **`0.5 片`** |
| **1 砖（标准砖高 Brick Height）** | `9.6 mm` | `24 LDU` | **`1.2 格`** | **`3.0 片`** |
| **SNOT 黄金比例（5 片 = 2 格）** | `16.0 mm` | `40 LDU` | **`2.0 格`** | **`5.0 片`** |

> **核心推论（5:2 定律与 4-LDU 支架定律）**：
> - **5:2 侧装对齐**：一块侧面竖放的 `2×N` 板或斜砖（宽度为 `2 格 = 16.0 mm`），其在竖直方向上恰好等于 **`5 片`（`1⅔ 块砖`）** 的高度！
>   - 因此 `11211`（1×2 四凸点侧装砖）和 `99207`（1×2-2×2 倒支架）的高度恰好是 **5 片**，上下两排侧凸点分别位于距底面 `1.25 片`（`0.5 格`）和 `3.75 片`（`1.5 格`）处；
>   - 同理，当头部侧面需要挂装 `2 格` 高（`5 片`）的 `3039` 斜面砖时，核心底座必须采用 **`99206`（`2 片` 高侧凸点增高板，侧凸点位于 `1.25 片` 中心）+ `3039`（`3 片` 高斜砖）= `5 片` 总高**，严禁使用普通 `1 片` 板（`1 + 3 = 4 片` 会导致侧砖悬空 `1 片`）。
> - **4-LDU（`0.2 格`）支架垂壁**：`99780`/`99781` 等乐高支架（Bracket）的水平板厚为 `1 片`（`8 LDU = 0.4 格`），但其垂直挂壁厚仅为 **`0.5 片`（`4 LDU = 0.2 格`）**，因此两块相对的支架或扣在 `1 片` 侧装板（`0.4 格`）外侧的 `99780` 支架，其外表面精确位于 `0.4 + 0.2 = 0.6 格` 处！

## 二、乐高拼插四大铁律（`brickkit validate` 强制执行）

### 铁律 1：凸点扣底孔与同轴把柄夹持定律（禁止虚假 `mount` 胶水）
乐高积木不是悬浮在空间里的几何体，而是**在一个平面上由圆点（凸点 Stud）与底孔（反凸点 Anti-stud / Tube）环环相扣**构成的：
- **严禁虚假 `mount` 胶水（`mount-disconnected` 错误）**：JSON 中的 `"mount"` 字段仅用于声明子零件挂载的父零件 ID，**绝不能绕过物理扣合校验**。若某零件指定了 `mount: "pXX"`，但 `partsConnected(child, parent)` 为 `false`，`brickkit validate` 将直接报 `mount-disconnected` 错误！
- **同向凸点扣底孔**：子零件底面（或支架垂壁）的某一个底孔中心，必须与父零件顶面或侧面的某一个凸点中心在三维空间中完全重合（误差 `< 0.12 格`），且**子零件的法向必须与该凸点的法向完全一致**。
- **把柄与夹口必须同轴且重合（Coaxial Bar-and-Clip）**：带夹子零件（`63868`、`60470`、`11476`）的夹口中心不仅要在三维坐标上对准带把柄零件（`48336`、`60478`、`2540`）的圆杆中心，而且**两者的圆杆轴向（`axis: 'x' | 'y' | 'z'`）必须完全平行（同轴）**！严禁出现夹口轴向沿 Z 轴、把柄圆杆沿 X 轴的 90° 异面错位。
- **半格居中必须使用跳线板（Jumper Plate Rule）**：标准板/砖的凸点位于 `.5` 格中心（如 `x = 0.5, 1.5`）。若要将 `1×1` 圆砖（`3062b`）或圆片（`4073`）居中放在 `2 格` 宽装甲的正中央（即 `at[0] = 0.5`，凸点中心在 `x = 1.0` 整数格线上），底下**必须垫装 `15573`（`1×2` 单凸点跳线板）或 `87580`（`2×2` 中心跳线板）**，绝不允许把 `1×1` 零件跨接在普通 `1×2` 板的两颗凸点中间！
- **严禁异向硬插**：绝不允许把一个朝上（`up: "+y"`）的圆柱或斜砖直接“插”进一块朝前（`up: "+z"`）的竖板表面——在真实乐高里，两个凸点面不可能互相穿透。

### 铁律 2：三维实体零穿模定律（Zero 3D Interpenetration）
`brickkit validate` 会调用 `partBoxes(p, def)` 计算模型中**每一颗零件（包括全部 6 向 SNOT 零件、转角砖与支架）在世界坐标系下的精确 3D 实体包围盒（AABB）**，并对所有零件对执行 `boxesCollide` 三维碰撞检测：
- **第一层侧装件（贴墙层）必须设 `snot: 0`**：
  例如父零件 `p13`（`11211` 侧凸点砖）的前表面位于 `z = 2`，则直接扣在 `p13` 侧凸点上的白色 `2×6` 板 `p15` 必须设置 `at[2] = 2, up: "+z", snot: 0`（占据 `z ∈ [2.0, 2.4]`）。
- **第二层侧装件（叠在第一层板凸点上）必须设 `snot: 1`**：
  扣在 `p15`（厚 `1 片`）正面凸点上的 `1×1` 角片 `p16` 必须设置 `at[2] = 2, up: "+z", snot: 1`（占据 `z ∈ [2.4, 2.8]`）。
- 如果两颗零件的 `snot` 层级写成了同一个值（例如都写成 `snot: 1`），它们就会在 `z ∈ [2.4, 2.8]` 空间完全重叠，被 `validate` 立即拦截并报告 `overlap（3D 穿模）` 错误。

### 铁律 3：方向转换必经转接件定律（SNOT Transition）
当实物照片中出现“在侧面护板外竖立一根朝上（`up: "+y"`）的能量柱/圆筒/天线”时，必须在结构中使用以下三种真实乐高转接方式之一：
1. **倒顺支架（Brackets）**：使用 `99780`/`99781`（1×2-1×2）、`99207`/`44728`（1×2-2×2）或 `36840`/`36841`（1×1-1×1）支架，在水平层与垂直面之间无穿模转接；
2. **四向/单向侧凸点砖（SNOT Bricks）**：使用 `4733`（四面侧凸点核心砖）、`87087`（单面侧凸点）、`47905`（对向双面侧凸点）或 `11211`（1×2 四凸点砖）；
3. **外挑水平托板**：从核心或侧板顶部向外探出一块水平板（如 `3023` 1×2 板，`up: "+y"`），让竖立圆柱扣在该水平板朝上的凸点上，且圆柱外壁与后方侧板外壁保持 `≥ 0` 的零穿透间隙。

## 三、使用 CLI 工具自动计算无穿模扣合坐标

不要手算或靠肉眼猜测 SNOT 小数坐标！BrickKit 提供了两个专用命令辅助 Agent 精确扣合零件：

### 1. 查看零件的 3D 包围盒与全部可用凸点：`brickkit studs`
```bash
node cli/brickkit.mjs studs examples/mecha.brick.json p13 --pretty
```
输出该零件的 3D 实体范围 `boxes`（`[x0..x1, y0..y1, z0..z1]`）、全部顶面/侧面凸点 `studs`（含编号 `index`、世界坐标 `pos` 与法向 `dir`）以及底面插孔 `receptors`。

### 2. 自动计算子零件扣合在指定凸点上的精确坐标：`brickkit snap`
```bash
node cli/brickkit.mjs snap examples/mecha.brick.json --parent p13 --stud 2 --part 3795 --receptor 4 --pretty
```
自动返回子零件底孔 `#4` 扣合到父零件 `p13` 的凸点 `#2` 上时的精确 `{ part, at, rot, up, snot: 0, mount }`，保证 **100% 凸点对齐且 0 穿模**。

## 五、三大典型复杂机构拼插详解（以双足机甲实物拆解为例）

在还原带有可动关节、侧面装甲与夹持式底座的复杂模型时，严禁把零件“贴”在表面，必须还原其真实的物理母子扣合关系：

### 1. 侧边四片机翼是怎么固定的？（端头夹板 `63868` 同轴夹持 `48336` 把柄 + 楔形翼板底孔扣合）
- **错误做法**：把 `60470`（侧边双夹板）扣在机翼正面的凸点上（既挡住了机翼正面的凸点，夹口轴向沿 Z 轴也与沿 X 轴的把柄圆杆垂直错位 90°）。
- **真实乐高拼法**：
  1. 胸腔核心肩部（`y = 19`）前后各向左右外挑安装 2 块带把柄板 `48336`（`p30..p33`），其水平把柄圆杆沿 **X 轴** 位于 `[-1.5, 19.5, 2.22]`、`[3.5, 19.5, 2.22]`、`[-1.5, 19.5, -0.22]`、`[3.5, 19.5, -0.22]`；
  2. 在机翼背面（贴墙层 `snot: 0`）各竖置一块 **`63868`（`1×2` 端头单水平夹板，`p56, p58, p60, p62`）**，其端头的水平 C 型夹口朝上伸出，轴向同样沿 **X 轴** 并与 `48336` 把柄圆杆在 `y = 19.5` 处 **0.000 mm 同轴咬合**；
  3. 每片 `2×4` 楔形翼板（`41769`/`41770`，`p57, p59, p61, p63`）置于外侧 `snot: 1` 层，**底面内侧的 2 个底孔（Anti-studs）直接扣合在背面 `63868` 顶面的 2 颗凸点上**，正面 4 颗凸点完全裸露，实现机翼绕把柄圆杆前后摆动！

### 2. 前后胸甲、侧边装甲与四根能量柱是怎么装上去的？（跳线板 `15573` + 内缩车灯砖 `4070` + 核心侧凸点零间隙扣合）
- **真实乐高拼法**：
  1. **前后胸甲与居中能量柱（跳线板扣胸甲凸点 + 4070 车灯砖 4-LDU 内缩面凑整层）**：
     - 前后胸甲 `2×4` 板（`p40, p44`）扣在核心 `11211` 侧凸点砖上（外表面位于 `z = 2.4` 与 `z = -0.4`，凸点朝 `+z` 与 `-z`）；
     - 跳线板 **`15573`（`1×2` 单凸点跳线板，`p41, p45`）** 以 `up: "+z", snot: 1` / `up: "-z", snot: 1` 直接扣在胸甲下排中央两颗凸点上，在 `x = 1.0` 正中央输出单颗水平凸点；
     - 车灯砖 **`4070`（`1×1` 内缩侧凸点车灯砖，`p41a, p45a`）** 以底孔扣在跳线板中心凸点上（`snot: 2`），并旋转使内缩 `4 LDU = 0.5 片` 的侧凸点朝上（`dir = "+y"`），从而在 **`y = 15.25 + 0.75 = 16.0`（精确整数片高）** 处提供朝上的凸点，承托 **`3062b`（`1×1` 竖纹圆砖，`p42, p46`，`y = 16..19`）** 与透明圆片（`p43, p47`，`y = 19..20`）。
  2. **左右侧边双层装甲与肩部能量柱**：
     - 核心左右两侧的 `11211` 侧凸点砖（`p28` `rot: 270` 朝 `-x`、`p29` `rot: 90` 朝 `+x`）在 `x = -1.0` 和 `x = 3.0` 壁面露出侧凸点；
     - **第一层彩色过渡板（`snot: 0`）**：`1×4` 板 `p76, p77`（蓝/黄）和 `p79, p80`（白/红）零间隙贴合在 `x = -1.0` 与 `x = 3.0` 侧凸点上；
     - **第二层主装甲板（`snot: 1`）**：`2×4` 板 `p48`（黑）和 `p52`（暗红）扣在第一层过渡板外侧凸点上；
     - **肩部能量柱锁固**：肩部外挑的 `48336` 把柄板（`p30..p33`）上方跨接 **`15573`（`1×2` 跳线板，`p49, p53`）**，将前后把柄板锁为一体的同时在 `z = 1.0` 中心提供单颗凸点，供 `3062b` 能量圆筒（`p50, p54`）与 `1×1` 顶饰片（`p51, p55`）居中竖立。

### 3. 底部双足、前后裙甲与 5:2 头部底座是怎么安装的？
- **真实乐高拼法**：

# 乐高拼插物理规律与防穿模规范

本文档规定了 BrickKit 将实物照片转化为 3D 乐高模型时必须遵守的**几何尺寸换算、凸点-底孔扣合规则、零穿模硬约束**以及 **12 大类 152 种标准零件目录**的使用方法。任何调用 BrickKit 的 Agent（Harness）或建模者在输出 `.brick.json` 时均受本规范与 `brickkit validate` 的强制约束。

---

## 一、乐高基础几何换算（5:2 定律）

乐高积木之所以能在水平与竖直六个方向（SNOT，Studs Not On Top）严丝合缝地拼插，源于其严格的 **LDU（LDraw 单位）比例**：

| 物理量 | 毫米 (mm) | LDraw 单位 (LDU) | BrickKit 格单位 (`stud`) | BrickKit 层单位 (`plate`) |
| :--- | :---: | :---: | :---: | :---: |
| **1 格（水平凸点间距 Stud Pitch）** | `8.0 mm` | `20 LDU` | **`1.0 格`** | **`2.5 片`** |
| **1 片（板厚 Plate Height）** | `3.2 mm` | `8 LDU` | **`0.4 格`** (`PLATE = 0.4`) | **`1.0 片`** |
| **1 砖（标准砖高 Brick Height）** | `9.6 mm` | `24 LDU` | **`1.2 格`** | **`3.0 片`** |
| **SNOT 黄金比例（5 片 = 2 格）** | `16.0 mm` | `40 LDU` | **`2.0 格`** | **`5.0 片`** |

> **核心推论**：
> - 一块侧面竖放的 `2×N` 板（宽度为 `2 格 = 16.0 mm`），其在竖直方向上恰好等于 **`5 片`（`1⅔ 块砖`）** 的高度！
> - 这就是为什么 `11211`（1×2 四凸点侧装砖）和 `99207`（1×2-2×2 倒支架）的高度恰好是 **5 片**：它的上下两排侧凸点分别位于距底面 `1.25 片` 和 `3.75 片` 处，两排凸点间距恰好是 `2.5 片 = 1.0 格`（`8.0 mm`），从而能让任何标准板/砖横过来严丝合缝地扣在侧面！

## 二、乐高拼插三大铁律（`brickkit validate` 强制执行）

### 铁律 1：凸点扣底孔定律（Stud-to-AntiStud & Clip-to-Bar Lock）
乐高积木不是悬浮在空间里的几何体，而是**在一个平面上由圆点（凸点 Stud）与底孔（反凸点 Anti-stud / Tube）环环相扣**构成的：
- **同向凸点扣底孔**：子零件底面（`y_local = 0`）的某一个底孔中心，必须与父零件顶面或侧面的某一个凸点中心在三维空间中完全重合，且**子零件的 `up` 朝向必须与该凸点的法向完全一致**。
- **把柄扣夹子**：带夹子零件（`60470`、`4085d`、`15712`、`30237`）的夹口中心必须对准带把柄零件（`48336`、`2540`、`26047`、`87994`）的圆杆轴线。
- **严禁异向硬插**：绝不允许把一个朝上（`up: "+y"`）的圆柱或斜砖直接“插”进一块朝前（`up: "+z"`）的竖板表面——在真实乐高里，两个凸点面不可能互相穿透。

### 铁律 2：三维实体零穿模定律（Zero 3D Interpenetration）
`brickkit validate` 会调用 `partBoxes(p, def)` 计算模型中**每一颗零件（包括全部 6 向 SNOT 零件、转角砖与支架）在世界坐标系下的精确 3D 实体包围盒（AABB）**，并对所有零件对执行 `boxesCollide` 三维碰撞检测：
- **第一层侧装件（贴墙层）必须设 `snot: 0`**：
  例如父零件 `p13`（`11211` 侧凸点砖）的前表面位于 `z = 2`，则直接扣在 `p13` 侧凸点上的白色 `2×6` 板 `p15` 必须设置 `at[2] = 2, up: "+z", snot: 0`（占据 `z ∈ [2.0, 2.4]`）。
- **第二层侧装件（叠在第一层板凸点上）必须设 `snot: 1`**：
  扣在 `p15`（厚 `1 片`）正面凸点上的 `1×1` 角片 `p16` 必须设置 `at[2] = 2, up: "+z", snot: 1`（占据 `z ∈ [2.4, 2.8]`）。
- 如果两颗零件的 `snot` 层级写成了同一个值（例如都写成 `snot: 1`），它们就会在 `z ∈ [2.4, 2.8]` 空间完全重叠，被 `validate` 立即拦截并报告 `overlap（3D 穿模）` 错误。

### 铁律 3：方向转换必经转接件定律（SNOT Transition）
当实物照片中出现“在侧面护板外竖立一根朝上（`up: "+y"`）的能量柱/圆筒/天线”时，必须在结构中使用以下三种真实乐高转接方式之一：
1. **倒顺支架（Brackets）**：使用 `99780`/`99781`（1×2-1×2）、`99207`/`44728`（1×2-2×2）或 `36840`/`36841`（1×1-1×1）支架，在水平层与垂直面之间无穿模转接；
2. **四向/单向侧凸点砖（SNOT Bricks）**：使用 `4733`（四面侧凸点核心砖）、`87087`（单面侧凸点）、`47905`（对向双面侧凸点）或 `11211`（1×2 四凸点砖）；
3. **外挑水平托板**：从核心或侧板顶部向外探出一块水平板（如 `3023` 1×2 板，`up: "+y"`），让竖立圆柱扣在该水平板朝上的凸点上，且圆柱外壁与后方侧板外壁保持 `≥ 0` 的零穿透间隙。

## 三、使用 CLI 工具自动计算无穿模扣合坐标

不要手算或靠肉眼猜测 SNOT 小数坐标！BrickKit 提供了两个专用命令辅助 Agent 精确扣合零件：

### 1. 查看零件的 3D 包围盒与全部可用凸点：`brickkit studs`
```bash
node cli/brickkit.mjs studs examples/mecha.brick.json p13 --pretty
```
输出该零件的 3D 实体范围 `boxes`（`[x0..x1, y0..y1, z0..z1]`）、全部顶面/侧面凸点 `studs`（含编号 `index`、世界坐标 `pos` 与法向 `dir`）以及底面插孔 `receptors`。

### 2. 自动计算子零件扣合在指定凸点上的精确坐标：`brickkit snap`
```bash
node cli/brickkit.mjs snap examples/mecha.brick.json --parent p13 --stud 2 --part 3795 --receptor 4 --pretty
```
自动返回子零件底孔 `#4` 扣合到父零件 `p13` 的凸点 `#2` 上时的精确 `{ part, at, rot, up, snot: 0, mount }`，保证 **100% 凸点对齐且 0 穿模**。

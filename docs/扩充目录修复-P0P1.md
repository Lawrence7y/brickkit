## 二、判定口径（与上一轮一致）

- **可用**：五连全通（build/validate/studs/snap/render+目视），占地/高度与实物相符，定义性连接接口在连接系统中有表示；参数化简化（素盒、矩形拱口等）不阻塞。
- **仅几何**：几何/占地/高度基本正确，但定义性连接接口缺失、错误或无法构成实际连接。
- **不可用**：硬失败——无法建模/校验/渲染，或参数体与实物身份矛盾（如占地错一格、整帧全白）。
- 无顶凸点件 `snap --stud 0` 失败属**协议内预期失败**，如实记录不另降级。

### 降级 2 件：底孔受体误禁（本次回归新发现，建议回修）

两件的官方 .dat **都含有真实底面反孔图元**，但生成器 `antistudCells` 逐格映射（`tools/gen-parts-catalog.mjs` `|fi-ri|≤0.35` 判格）只支持「实例位=单格中心」的 stud3 类；**stud3a/stud4a 簇实例的中心落在格点边界（覆盖 2×2 格）**，映射失败后写入空数组 → 按修复策略被当作「底面无反孔」禁用：

- **3299**（3× stud4a @ (±20,0),(0,0)，yUp=−1.75）：受体 9→1，剩余 1 个 i=−1,k=−1 中心受体位于半格位 → builder 反向扣合产出非整数 `at=[-1.5,3,-0.5]` → assert 失败，上轮可用的垫砖能力丢失。
- **3049b**（1× stud3a @ (0,20,0)）：受体 4→0，builder 报「没有第 0 号底孔：该零件共 0 个底孔」。

追踪命令：`node out/ext-audit2/trace3.mjs`（connectorInstancesFromText 逐件列出 antistud 实例，3299/3049b 均非零）；实测命令：`node out/ext-audit2/test-reverse-mount.mjs`。修复方向：簇实例按 2×2 展开为 4 格（stud4a）或按实际覆盖格写入 antistudCells，再重跑生成器。

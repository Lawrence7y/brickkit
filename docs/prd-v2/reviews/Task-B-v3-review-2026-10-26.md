## 2. V3-01 / P0：正确答案被直接绘制在输入图像中

源码：`tools/brickvlm/gen_dataset.py:71`、`:87`、`:234`、`:246`。

状态图由 `draw_render_state_image(target_cand_idx, has_struct_error)` 生成：

- 正确候选的徽标画蓝色；
- 有结构错误时把该徽标画红色；
- 其他候选画白色。

这把动作标签与结构标签直接编码进了模型输入。图像可以正常打开、SHA256 可以真实匹配，但这不能成为真实说明书/装配任务证据。

独立图像探针只做颜色统计，不加载 checkpoint、不读取零件定义、不计算连接几何，得到：

| 颜色规则 | 结果 |
|---|---|
| 选择蓝色/红色徽标所在的候选 | 150 / 150 动作正确，100% |
| 看到红色就判断结构错误 | 75 / 75 结构分类正确，100% |

因此四候选随机 25% 不足以作为本数据集的有效比较基线。颜色规则已能全对，模型的 68.67% 不能证明理解了积木的结构或装配意图。

示例：[状态图](../../../out/prd-v2/run-20261026-v3/B/dataset/images/smp-ho-00453_render.png)、[所谓说明书目标图](../../../out/prd-v2/run-20261026-v3/B/dataset/images/smp-ho-00453_manual.png)。它们是统一的绘制模板，并非所标套装的步骤或实际装配状态。

目标图中的高亮可以来自真实的装配目标；但当前决策前的状态图不能由尚未选择的正确候选编号或错误标签直接上色。第一版 smoke 可使用这种任务，必须明确叫“颜色标记分类”，不能计作领域 R5。

## 3. V3-02 / P0：族名称隔离了，实际输入内容没有隔离

本次按文件内容哈希检查，而非只比较文件名或样本 ID：

- 全部样本的当前状态 PNG 只有 **8 种不同内容**；
- 300 张 holdout 状态图全部与 train 中图像字节相同；
- 当前训练和评测只读取 `images[1]` 状态图，没有使用 `images[0]` 说明书目标图；
- `part_id` 不影响目标图的砖形状，`draw_manual_step_image` 画的都是相同双凸点矩形；
- 套装 family/model 字符串没有从对应套装几何或说明书读取，不能据此声称真实未见套装泛化；
- 数据仍将这些 PIL 模板标为 `real_manual`、`hasManualGroundTruth=True`、`manual_review_curriculum`；候选与 stateHash 也仍由编号公式生成。

公开的文件字节重复不必在所有任务中都构成泄漏，但在本提交中，它恰好重复了模型实际消费的唯一视觉输入，且输入还直接带正确答案，无法满足 PRD 的模型族/结构留出要求。

正确修法是以真实装配图/组件来源划分 split，渲染实际零件、实际连接和目标状态；标明 synthetic 与 real_manual；由真实引擎生成候选。不能继续更换族名称或增加同模板 PNG 数量。

## 4. V3-03 / P0：视觉编码器没有训练/保存，评测重新随机初始化

源码：`visual_encoder.py:53`、`train_r3_pilot.py:37`、`:40`、`:166`、`evaluate_r5.py:30`。

- `extract_from_path` 使用 `torch.no_grad()`，编码器未参与反向更新；
- optimizer 只接收 `model.parameters()`，不包含视觉 CNN；
- checkpoint 只保存 BrickVLMCompact，本次加载的权重中没有 CNN/visual_encoder 参数；
- 评测直接新建随机 `SimpleVisualEncoder`，没有加载训练时的同一视觉编码器；
- 缺图或解码失败又被 catch 后替换为零向量，没有作为必然失败关闭该样本。

可以使用冻结视觉编码器，但必须锁定、保存并复用同一份编码器/预训练权重、图像变换及版本。当前随机初始化不构成可复现的完整视觉模型。

本次固定同一核心 checkpoint、同一批 16 个样本，仅改变未保存 CNN 的初始化 seed：

| 比较 | 结果 |
|---|---|
| 视觉特征最大绝对差 | 约 0.21548 |
| 动作 logit 最大绝对差 | 约 0.32517 |
| 16 个样本的 argmax 是否改变 | 本次为 0 个；不夸大为已证实分类结果变化 |

该实验直接证明同一 checkpoint 不能唯一重现其视觉表示和完整 logits。既有训练报告没有提供能恢复训练时 CNN 的资料。

3. 当前图只标统一样式的接口 ID，不从正确候选或结构标签决定颜色。用实际目标与当前结构差异生成标签，进行同一零件不同挂点、同一状态不同目标等反例。

5. 分别做无视觉、目标图打乱、候选重排、颜色徽标规则等对照，确认模型依赖正确的任务信息。按真实结构/来源去重和留出。

7. 重建说明书标注与 Qwen 真实训练入口；没有实现训练循环时返回清晰的 not-implemented/preview，而非完成。
8. 之后再扩大数据、运行领域 SFT 和独立测试。当前阻断原因包含 B 自身的数据/模型/评测问题，不能全部归因于等待 A。

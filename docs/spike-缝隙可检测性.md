## 1. 实验方法

### 1.1 照片与区域选择

逐张目视 6 张原图后，选 3 张有大片「同色相邻零件」区域的照片，覆盖任务点名的三类交界：

| 照片 id | 文件 | 同色区域 |
|---|---|---|
| `lantern_top_detail` | 1792845158564.jpg | 两块淡紫 2×4 板的 V 形交界 + 粉色 1×2 砖圈对接缝 |
| `lantern_a090_e00` | 1792845158626.jpg | 粉色圆板柱相邻段（上轨 4 缝 + 下轨 5 缝） |
| `lantern_base_detail` | 1792845158492.jpg | 绿色十字板相邻交界（主缝 + 左下缝） |

### 1.2 候选与对照线段

- **缝隙候选**：同色相邻零件的可见交界线段，端点由「带网格放大裁剪目视 + 垂直亮度剖面数值校准」确定（坐标硬编码于脚本 `PHOTOS` 常量）。
- **对照线段**：方向、颜色区域与候选相同，但位于**单一零件内部不存在边界**的网格位置。8626/8492 的对照按几何构造定义（圆砖段/芯段/板面中线，经确认其两侧为同一零件）；8564 的淡紫板整体为单一零件、内部任意平行线均无边界，唯一污染源是凸点/孔洞亮暗斑，故在脚本内做**平坦度扫描**（2 侧 × 4 偏移 × 3 沿缝区间 = 24 个候选位置实测），取每侧最平的 3 条为对照。扫描全部结果见 §3.1——它本身量化了「凸点掠过网格线」的假缝风险。

每条线段取 **3 个采样位**（t = 0.2 / 0.5 / 0.8），在每个采样位沿垂直于线段方向提取 **±42px 亮度剖面**（原图灰度、双线性插值、沿线段方向 ±10px 平均降噪）。

### 1.3 指标、逐位判据与段级聚合规则（v2 显式声明）

每个采样位独立计算：深度 = 两肩窗（±28..42px）像素中位数 − 中心窗（±25px）谷底（8-bit 亮度）；局部噪声 σ = 肩窗像素标准差；SNR = 深度/σ；半高宽 FWHM（亚像素）。

**逐位判据**两档：

- **判据 A（任务原判据）**：SNR ≥ 3 且 FWHM ≥ 1px；
- **判据 B（v2 修订判据）**：A 且 **depth ≥ 5 级**（8-bit）——为抑制超平坦面上的 shading 误触发（实证见 §3.2）。

**段级聚合规则**（3 个采样位 → 1 个段判定；v2 起显式声明并全量对比，实现见 `tools/spike-seam-test.mjs` 文件头与 `measureSegment()`）：

| 规则 | 定义 | 备注 |
|---|---|---|
| **R1 maxDepth（主规则）** | 取 depth 最大的采样位为代表位，判据 B 在代表位成立即段检出 | 首轮实验实际使用但未声明的规则（旧版 `tools/spike-seam-test.mjs:193`），v2 声明；§2 各表数值即该代表位数值 |
| R2 maxSNR | 取判据 B 采样位中 SNR 最大者 | |
| R6 maxSNR（判据 A） | 在判据 A 采样位中取 SNR 最大者 | 复核员设想的聚合方式 |
| R3 多数表决（判据 A） | ≥2/3 位满足判据 A | 复核员设想 |
| R4 多数表决（判据 B） | ≥2/3 位满足判据 B | |
| R5 混合（v2 建议） | ≥2/3 位满足判据 B，或任一位满足判据 B 且 (depth≥20 或 SNR≥10) | 兼顾多数表决与单强证据，阈值在本数据上后验调得（见 §4(d) 的过拟合声明） |

各规则的检出/误检全量对比见 §2.5。结论方向（真缝信号远强于对照）在所有规则下一致，但两个头条数字（86%、误检率）依赖聚合规则与判据档位，故全文同时给出。

## 3. 关键发现（对 FR-6.1 的直接输入）

### 3.1 段端部污染是首要失败模式

主缝的端部常与异色零件（8564 A4 下端接深蓝板）、斜棱亮带（8492 G1/G4 端部接臂缘倒角带）相邻，±42px 肩窗被污染后 σ 从 2–7 飙到 18–27，SNR 崩到 ≤1.5。缝的中段全部可检出。**FR-6.1 的段级采样必须带「端部低置信」处理**：肩窗内出现异色边界或 σ>15 时标 `lowConfidence`，或自动收缩段长。

### 3.2 聚合规则与判据档位决定结论（v2 修订）

- **C6 误检机制**（8626 上轨凸包2中线）：逐位 depth=[0.8, 0.7, 2.8]、SNR=[2.3, 1.9, 7.6]、FWHM=[3.9, 4.6, 9.7]。旧判据（SNR≥3 且 FWHM≥1）下 1/3 位满足，max-depth/max-SNR 聚合均误检。其 σ=0.4 是全数据最平坦的面——**纯 SNR≥3 判据在超平坦面上把 ~3 级 shading 波动当缝**。
- **多数表决的代价**（复核员指认，脚本复现属实）：真缝 B6（SNR [1.7,2.7,9.9]）与 G2（[1.0,18.8,2.3]）均仅 1/3 位满足旧判据，纯多数表决把可检出率从 86% 压到 76%（16/21），肩窗干净段从 18/18 降到 16/18。v1 报告「全部真缝 ≥2/3 位触发」的论断**错误**，特此更正。
- **修订建议**：**深度下限（判据 B）是主修复**——本实验中仅有的两个「被某规则误判为缝」的对照位，C6（触发位 depth=2.8<5）与 H3（触发位 depth=1.4<5），加 depth≥5 后即全部被拒；而 C1/C2 这类大 depth（23.2/24.5）但 σ≈21.7 的离焦对照由 SNR≥3 拒绝，两条约束互补。加判据 B 后六种聚合规则下对照误检全部归零，且 18 段真缝在 R1/R2/R5 下检出不变。纯多数表决（R3/R4）不可取；若要空间一致性，用 R5 混合规则（多数 或 单位强证据 depth≥20/SNR≥10），本数据上 18/21 & 0/18。**过拟合声明**：R5 的阈值（5/20/10）是在本数据上后验调得的，仅作为 FR-6.1 的初始建议，必须在 §9 合成回归集上重新标定。

### 3.3 斜棱折痕 ≠ 缝（假候选教训）

8492 绿十字区目视可见的多条平行暗线中，只有主缝与左下缝是真零件交界；其余（间距 80px 的平行线）经 4× 放大核对为**板缘倒角/防反孔口沿的折痕**。若把折痕当候选，会同时虚增「可检出率」分母与「误检」语义。合成回归集（PRD §9）必须包含斜棱折痕作为负面样本。

### 3.4 深色零件在现有光下无法定义候选

两张照片中的深蓝板（8564 棚顶下层、8492 底座）在暖光下**连一条可目视确认的同色缝都找不到**——这些区域在候选定义阶段就弃权（未纳入分子分母）。这是散射光对深色件失效的直接证据，与 PRD §12「深色零件低对比区」风险一致。

### 3.5 凸点掠过网格线的假缝风险（量化）

8564 对照平坦度扫描（24 个网格位置）实测：距交界 ±180/260px 的两圈位置 meanDepth 6.1–19.7 级（凸点/孔洞亮暗斑所致），±220px 一圈 0–2.9 级。即：**网格线若与凸点缘擦过，可产生 10–20 级的假深度**。生产中网格对齐后此风险更高，需按 §3.2 的深度下限+聚合规则抑制。另 C4 的 t=0.2 位 FWHM=353.8px（平台渐变被误判为超宽谷）提示 FWHM 需设上限（建议 ≤45px）。

## 4. 四问结论

### (a) 散射光+原图分辨率下，缝隙可检测率是多少？

**段级 86%（18/21，主规则 R1）**；全部 3 段失败均为段端部异色/斜棱污染，**肩窗干净的段在 R1/R2/R5 下 18/18 = 100%**（多数表决 R3/R4 下 16/18），检出缝代表位 SNR 4.8–45.1（中位 14），暗带深度 14.3–66 级（8-bit）。在普通室内暖光（非受控散射、非侧光）、4096×3072 原图下，**亮色（粉/淡紫/绿）零件的同色缝是强信号**，PRD §1「缝隙是可确定性检测的强先验」在本数据集上成立。该数字依赖 §1.3 声明的聚合规则与判据档位（敏感性见 §2.5：76%–86%）。

### (b) 换算到 PRD rectify 分辨率（1 凸点=80px，即 1mm=10px）后，一条缝对应多少像素、是否可测？

实测暗带 FWHM 0.37–0.71mm（各照片检出缝均值 0.37/0.60/0.71mm），rectify 后为 **3.7–7.1px**——≥3px，可测。需注意：① 原图 mm/px（0.040–0.051）到 rectify（0.1mm/px）是 2–2.5× 重采样合并，单像素 SNR 会按 ~√2 下降，但积分对比度不变，按现深度（14.3–66 级）仍远超门限；② 机械缝本身仅 ~0.05–0.1mm（rectify 下 0.5–1px 亚像素），**可检测信号是「缝隙阴影+倒角暗带」而非机械缝**，FR-6.1 的 ±2 LDU（8px）对齐容差足以覆盖；③ 本实验 6–38px 的暗带宽度也说明剖面搜索窗需 ≥±25px（原图尺度），rectify 后相应收窄。

### (c) raking 侧光是否应升级为一期硬前提？

**不应升级为一期硬门禁，维持 FR-4.5 原计划（P0=warning，P1 起 error）**。理由：本实验在无侧光的暖光下已达到段级 86%/干净段 100%（R1/R2/R5）的可检出率，侧光并非亮色件缝检的必要条件；且一期门禁过严的流失风险（PRD §12）尚无数据支撑放宽。但有两点必须跟进：① **深色主导的模型应强制侧光**（§3.4：深蓝板在现有光下零候选）——建议作为 `check-photos` 的条件规则（按模型主色/区域亮度触发）而非全局硬门禁；② 把「散射光下缝检」纳入 §9 合成回归集持续回归，二期再依据数据决定是否升 error。

### (d) 对 FR-6.1 段级概率阈值的具体建议（v2 修订）

在「垂直剖面、肩窗中位数平台」的段级判定上，建议：

1. **逐位判据用判据 B**：`depth ≥5 级` 且 `SNR ≥3` 且 `1px ≤ FWHM ≤45px`。深度下限是抑制超平坦面误检的主修复（C6 全部位 depth≤2.8 被拒）；FWHM 上限防平台渐变误判（C4 出现 353.8px 退化为宽谷）。
2. **段级概率 p 分段标定**（以本实验分布为初值，在合成集上回归）：depth≥15 且 SNR≥8 → p≥0.9；depth 5–15 → p 在 0.2–0.9 线性插值；depth<5 → p≤0.2（无论 SNR）。
3. **聚合规则用 R5 混合而非纯多数表决**：≥2/3 位满足判据 B，**或**任一位满足判据 B 且 (depth≥20 或 SNR≥10)。纯多数表决会牺牲 B6/G2 这类「单强证据」真缝（86%→76%）；R5 在本数据上 18/21 & 0/18。**阈值后验调得，须在 §9 合成集回归后才能定稿**。
4. **`lowConfidence` 触发条件**（全部有本实验实证）：肩窗含异色边界或 σ>15（A4/G1/G4）；|谷底偏移|>15px（配准不良，本实验手动布线偏移最大 23px）；饱和/欠曝像素>5%；深色区（建议 depth 门限对亮度<80 的面加倍）。
5. **负面样本必须进合成回归集**：斜棱折痕（§3.3）、段端异色邻接、超平坦面、凸点掠过网格线（§3.5）、深色零件。

```bash
node tools/spike-seam-test.mjs
```

## 6. 边界与假设声明

1. **选段偏置**：候选线段选在缝可见处（任务即「可见交界的可检测性」）；无法定义候选的区域（深蓝板、离焦前景）不计入分子分母——真实全场景可检出率必然低于 86%。
2. **mm/px 为估计值**：三张照片的锚点与不确定度见 §1.4（8492 两锚点互差 20%）。检出结论（SNR≫3）对 ±20% 尺度误差不敏感；(b) 问的 rectify 换算只依赖 rectify 固定尺度，与原图尺度误差无关。
3. **光照非受控**：室内暖光多角度，未标定白平衡/曝光；结论仅代表「非侧光普通室内光」这一档。
4. **对照选点方法**：8626/8492 按几何构造（单零件内部中线）；8564 由 24 点平坦度扫描选最平 6 点——该选择使误检率偏向乐观，故同时报告全部扫描分布（§3.5）作为生产风险的量化补充。
5. **聚合规则与判据档位的声明**：§2 各表数值为主规则 R1（max-depth 代表位）数值；首轮实验曾以未声明方式使用该规则，v2 已声明并给出六规则敏感性（§2.5）；R5 混合规则的阈值在本数据上后验调得，存在过拟合风险。
6. **边界遵守**：仅改动 `tools/spike-seam-test.mjs` 与本报告两个仓库文件；照片目录只读未改动；检查过程使用的临时裁剪图/辅助脚本均写在系统临时目录（非仓库、非照片目录）并于实验后删除。

# 拍摄规范

目标：让识别程序（和人）从照片里**看清每一块零件的位置、颜色、朝向**，并知道每个可开合设计打开后里面是什么。

> 拍完后运行 `brickkit check-photos photos.json --dir 照片目录`，它会列出缺少的机位和不达标的照片。
> 不确定要拍什么时，运行 `brickkit photo-plan --model model.brick.json` 生成拍摄清单。

---

## 1. 拍摄环境

| 项目 | 要求 |
|---|---|
| 背景 | 纯色、哑光，与模型颜色反差大（浅灰卡纸最通用；白色模型用深灰） |
| 尺寸参照 | 模型下垫 **8 mm 方格纸**或乐高底板（1 格 = 1 个凸点），写进 `capture.reference` |
| 正面标记 | 在方格纸正面一侧贴一条彩色胶带，所有照片都以它为 0°（写进 `capture.frontMarker`） |
| 光线 | 柔和散射光（窗边自然光 + 白色泡沫板补光）；**不开闪光**，避免透明件和亮面反光 |
| 相机 | 手机**主摄 1×**，不用广角和数码变焦；关闭人像、美颜等效果 |
| 构图 | 模型占画面 **60–80%**，完整入画不裁切 |
| 分辨率 | 长边 **≥ 3000 px**，导出原图，不压缩 |
| 对焦曝光 | 长按锁定对焦和曝光（AE/AF 锁），整组照片保持一致 |
| 转盘 | 推荐用转盘（或转动方格纸），相机位置固定，只转模型 |
| 可开合 | **一次只打开一个**设计，拍完复原再拍下一个 |

---

## 2. 方位约定

- **方位角 azimuth**：从上往下看，**0° = 正面**（+z），**90° = 站在正面时的右手边**（+x），180° = 背面，270° = 左侧。
- **俯角 elevation**：0° = 与模型同高平视，30° = 斜上方，90° = 正上方往下看，−90° = 底面。

---

## 3. 必拍清单

### L1 外观（必拍 14 张，全部是“合上”状态）

| 机位 | 方位角 | 俯角 | 张数 | 文件名示例 |
|---|---|---|---|---|
| 斜上方一圈 | 0、45、90、135、180、225、270、315 | 约 30°（15–50°） | 8 | `ext_a045_e30.jpg` |
| 平视 | 0、90、180、270 | 约 0°（−10–15°） | 4 | `ext_a090_e00.jpg` |
| 顶视 | — | 70–90° | 1 | `ext_top_e90.jpg` |
| 底视 | — | 翻过来拍底面 | 1 | `ext_bottom.jpg` |

方位角允许 ±20° 误差。底面实在不能拍（例如粘在展示架上），在 `skipped` 里写明原因：

```json
"skipped": [{ "slot": "bottom", "reason": "底板粘在展示架上，不能翻过来" }]
```

### L2 可开合设计（每一个都要拍，拍完复原）

| 内容 | 要求 | `kind` / `state` | 文件名示例 |
|---|---|---|---|
| 完全打开 | **≥ 2 个不同角度** | `mechanism` / `open` | `mech_door_open_a000_e20.jpg` |
| 打开后露出的内部 | ≥ 1 张 | `interior` / `open` | `mech_door_interior_a000_e10.jpg` |
| 半开（合页 / 滑动） | 建议 1 张，用来判断转轴、滑轨位置 | `mechanism` / `half` | `mech_door_half_a000_e20.jpg` |
| 取下的部件 | 可取下的部件单独拍**顶面、底面各 1 张** | `module` | `mech_roof_module_top.jpg` / `mech_roof_module_bottom.jpg` |

`mechanism` 字段填可开合设计的 id（例如 `door`、`roof`），与模型 `mechanisms[].id` 一致。

### L3 细节特写（建议）

小零件、侧面拼装（SNOT）、透明件、贴纸、颜色相近的地方，各拍 1 张近景：`detail_door_handle.jpg`，`kind: "detail"`。

### L4 分层拆解（可选，最准确）

如果愿意拆，每拆掉一层拍一张顶视：`layer_03_top.jpg`，`kind: "layer"`，`layer: 3`。有了分层照片，内部被遮挡的零件就不用靠推断（`status: inferred`）。

---

## 4. 命名规则

```
ext_a{方位角3位}_e{俯角2位}.jpg              外观：ext_a000_e30.jpg
ext_top_e90.jpg / ext_bottom.jpg              顶视 / 底视
mech_{设计id}_{open|half}_a{方位}_e{俯角}.jpg  可开合：mech_door_open_a045_e30.jpg
mech_{设计id}_interior_a{方位}_e{俯角}.jpg     内部：mech_door_interior_a000_e10.jpg
mech_{设计id}_module_{top|bottom}.jpg          取下的部件
detail_{描述}.jpg                              特写
layer_{层号2位}_top.jpg                        分层拆解
```

文件名只是约定，真正的依据是 `photos.json` 里的字段。

---

## 5. 照片清单 `photos.json`

```json
{
  "format": "brickbuild-photos",
  "version": "0.2",
  "model": "cottage.brick.json",
  "capture": {
    "device": "iPhone 15 主摄 1x",
    "background": "浅灰色哑光卡纸",
    "reference": "模型下垫 8mm 方格纸",
    "lighting": "窗边自然光 + 白色泡沫板补光，未开闪光",
    "frontMarker": "方格纸正面一侧贴了红色胶带",
    "turntable": true
  },
  "mechanisms": [
    { "id": "door", "label": "前门", "type": "hinge" },
    { "id": "roof", "label": "屋顶", "type": "removable" }
  ],
  "skipped": [{ "slot": "bottom", "reason": "底板粘在展示架上，不能翻过来" }],
  "photos": [
    { "id": "ext_a000_e30", "file": "ext_a000_e30.jpg", "kind": "exterior", "azimuth": 0, "elevation": 30, "state": "closed" },
    { "id": "mech_door_open_a000_e20", "file": "mech_door_open_a000_e20.jpg", "kind": "mechanism", "mechanism": "door", "state": "open", "azimuth": 0, "elevation": 20 },
    { "id": "mech_roof_module_top", "file": "mech_roof_module_top.jpg", "kind": "module", "mechanism": "roof" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `kind` | `exterior` 外观 / `bottom` 底面 / `mechanism` 可开合 / `interior` 内部 / `module` 取下的部件 / `detail` 特写 / `layer` 分层 |
| `azimuth` / `elevation` | 方位角 / 俯角（度），见第 2 节 |
| `state` | `closed` 合上 / `open` 打开 / `half` 半开 |
| `mechanism` | 对应的可开合设计 id |
| `layer` | `kind = layer` 时拆到第几层 |
| `width` / `height` | 像素尺寸；`check-photos --dir` 会自动读取 |
| `note` | 备注，例如“门开到约 45°” |

`mechanisms` 用于模型还没建好时先登记有哪些可开合设计，`check-photos` 会据此检查每个设计的照片是否齐全。完整示例见 `examples/cottage.photos.json`。

---

## 6. 自查清单

- [ ] 14 个外观机位都有（或底视写了 `skipped`）
- [ ] 每个可开合设计：打开 ≥ 2 个角度、内部 ≥ 1 张、可取下部件顶 / 底各 1 张
- [ ] 每张照片模型完整、清晰、无反光、长边 ≥ 3000 px
- [ ] 方格纸和正面标记在每张外观照片里都看得见
- [ ] 所有可开合设计已复原
